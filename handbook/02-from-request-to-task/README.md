# 2. Kliendisoovist arendusülesandeni

> **Põhiküsimus:** kas tegeleme päris ja olulise probleemiga?

Selles osas algab meeskonnatöö. Tellija soov on alles algus: enne lahenduse valimist tuleb aru saada, kellel on probleem, kui tõsine see on ja mida me sellest päriselt teame. Osa lõpus on meeskonnal põhjendatud lähteülesanne ja esimene avaldatud versioon.

Näidetes kasutame väljamõeldud kliendisoovi: *kool soovib oma tunniplaani veebilehte muuta kaasaegsemaks*. Sama näide on demo-repos `tiim-demo-tunniplaan`.

## Mida sa õpid

Osa lõpuks:

- eristad soovi, probleemi ja lahendusideed;
- sõnastad probleemiväite ning eristad tõendit, tõlgendust ja oletust;
- tead, millised rollid tarkvaraarenduses on ja miks neid vaja on;
- kontrollid võõra materjali litsentsi enne selle kasutamist;
- koostad meeskonnaga lähteülesande ja paned otsuse kirja;
- planeerid tööd Kanbani tahvlil ja annad ajahinnangu;
- töötad ühises repos: `pull`, tag ja release.

## Eeldused

Osa 1 Giti töövoog: Issue → haru → commit → push → pull request → ülevaatus.
