# Pull request'i kontrollnimekiri

## Autor

- [ ] Pull request lahendab viidatud Issue.
- [ ] Muudatus on tehtud eraldi harus.
- [ ] Commit'ide sõnumid kirjeldavad tehtud muudatusi.
- [ ] Vaatasin diff'i enne ülevaatuse küsimist üle.
- [ ] Lingid töötavad ja Markdown avaneb korrektselt.
- [ ] Failides pole tundlikku ega põhjendamatult isiklikku infot.
- [ ] Selgitasin kirjelduses, mida muutsin ja miks.

## Ülevaataja

- [ ] Saan muudatuse eesmärgist aru.
- [ ] Otsuse põhjendus toetub probleemile või uuele infole.
- [ ] Alternatiivid ja kompromissid on nähtavad.
- [ ] Esitasin vähemalt ühe sisulise küsimuse või põhjendasin heakskiitu.
- [ ] Ma ei hinnanud ainult vormistust.

## Pärast ülevaatust

- [ ] Autor vastas kommentaaridele.
- [ ] Vajalikud parandused on tehtud.
- [ ] Ülevaataja kinnitas lõpptulemuse.
- [ ] Pull request ühendati kokkulepitud sihtharusse.
