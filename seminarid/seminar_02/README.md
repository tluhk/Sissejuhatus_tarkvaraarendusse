# Seminar 2: kliendisoovist arendusülesandeni

Alusta [slaididest](slides.md) või ava [HTML-esitlus](slides.html). Slaidid annavad seminari järjekorra ja põhisõnumid. Iga teema juures olev link viib põhjalikuma selgituse või tööjuhendini.

Iseseisvalt õppides loe slaidid koos lingitud peatükkidega, tee probleemikandidaatide harjutus ning läbi tiimi töövoog. Kodutöö tegevused ja esitamise sammud on eraldi failis [homework.md](homework.md); taustaselgitused leiad [kodutöö ja release'i peatükist](peatukid/07-kodutoo-ja-release.md).

Õpetajale: [ettevalmistus ja ajakava](opetaja-juhis.md).
