# Eeltegevused

Enne esimest loengut tuleks teha ära järgmised tegevused:

## Git-i paigaldus

Paigalda oma arvutisse git: https://git-scm.com/downloads

## Töövahendid

Paigalda Git ja [Visual Studio Code](https://code.visualstudio.com/) ning loo GitHubi kasutajakonto. Kursusel kasutame Giti peamiselt terminalis. Sama töövoogu näitame paralleelselt VS Code'i Source Control vaates ja võid seda kasutada. Esimeses kodutöös harjutame terminali põhikäskude ringi. Windowsis kasuta kursuse juhendites Git Bashi.

Esimeses seminaris kasutame GitHubiga ühendumiseks HTTPS-i. SSH-võtmeid pole vaja seadistada. GitHub Desktopi kursusel ei kasuta.
